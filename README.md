# Pr1ntpool

### Better printing, together.

Group printing shouldn't mean duplicate uploads, separate queues, and lots of trips. **Pr1ntpool brings everyone together around one print job**: share a document, coordinate a group, and pick up when it works for you.

**One document. One link. Everyone’s copies, ready at their slot.**

## Try the demo

| Role | Email | Password | Destination |
|---|---|---|---|
| Customer | `customer1@demo.com` | `password` | Customer dashboard |
| Print shop | `printshop1@demo.com` | `password` | Shop order board |

## The flow

1. Upload one PDF and keep print settings consistent.
2. Share the pool link with your class, team, or club.
3. Choose a pickup slot and skip the separate trips.

## Run locally

```bash
npm install
npm run dev
```

For authentication, configure `VITE_SUPABASE_URL` and `VITE_SUPABASE_PUBLISHABLE_KEY` in a root `.env` file.
